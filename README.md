# Editreo for Claude Code

Video editing styles for Claude Code by Marketing Musthak. Give Claude a raw talking-head video and get a finished 9:16 reel with captions, motion graphics and sound design. Editing runs on your own Windows or Mac computer with your own Claude plan. The styles need an Editreo subscription key.

## Install

Send these one line at a time, each as its own message:

```
/plugin marketplace add editreo/editreo
/plugin install editreo@editreo
/editreo:activate ER-XXXX-XXXX-XXXX-XXXX
/editreo:setup
```

Then, for example: `/editreo:night-lime edit my-video.mp4`

`/editreo:styles` lists the styles in your plan. One key works on one computer. To activate, renew and download styles, the plugin sends your key and a hashed computer ID to the Editreo license server. At session start it checks your license and that the video tools are installed. Your videos are never uploaded.
